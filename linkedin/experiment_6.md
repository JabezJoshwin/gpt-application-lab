I've put together a modular Python implementation for Experiment 6: Educational medical symptom assistant.

The application includes structured symptom input; separation of reported and denied symptoms; missing-information prompts; follow-up questions; an application-controlled disclaimer and report saving.

The implementation has passed 10 offline tests covering application logic and model request/error handling. Live OpenAI GPT-4 execution and output review are the next verification step, so I’m sharing this as an implementation rather than a validated model demo.

Code: https://github.com/JabezJoshwin/gpt-application-lab/tree/main/MedicalAssistant

This is an educational prototype, not a diagnosis or clinical decision tool.
